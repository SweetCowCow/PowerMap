## Goals / Non-Goals

**Goals:**

- 去掉明確重複的變電所（被包住、而且沒有名稱或同名），每筆都留下紀錄
- 大觀的一廠、二廠容量都出現在地圖上

**Non-Goals:**

- 不改 `same` 的容量規則
- 不處理只是距離近、範圍不重疊的變電所
- 不處理只有點的變電所（目前 1 個）
- 不改變電所的屬性欄位和排序

## Decisions

### 只去掉包含關係中沒有名稱或同名的那個

兩個變電所 A、B 都是面（Polygon 或 MultiPolygon），在 EPSG:3826 計算：A 和 B 相交的面積 ≥ A 面積的 90%，而且 A 的面積小於 B，就說 A 被 B 包住；A 被多個變電所包住時，B 取面積最小的那個。

- A、B 只有一個有名稱：去掉沒有名稱的那個（不論在裡面或外面），另一個記為 `kept_osm_id`
- 兩個都沒有名稱，或名稱相同：去掉 A（裡面那個）
- 名稱不同：都保留

一個變電所最多被去掉一次（依輸出排序，先遇到的組合決定）。目前沒有連鎖情況。

**修正（2026-11-13 實作時）**：提案時把六家、隘口看反了，實際是沒名稱的大範圍包住有名稱的建物。原本「只去掉裡面那個」的規則只會去掉 2 個，改成「去掉沒名稱的那個」才符合討論時要去掉這 4 處重複的目標；沒名稱的範圍只有 `power=substation` 標籤，去掉不會失去資訊。

名稱不同時保留，因為那通常是廠區內另一個有名稱的設施（例如同盟變電所和電力修護處）。替代方案是「被包住就去掉」，但會刪掉有名稱的不同設施，所以不採用。

### 去重紀錄寫成獨立檔案

新增 `data/processed/substation_dedup_log.csv`，欄位和設施的 `dedup_log.csv` 相同：`action,kept_osm_id,dropped_osm_id,reason,distance_m`。`action` 為 `substation_contained`，`reason` 為 `unnamed` 或 `same_name`，`distance_m` 是兩者代表點在 EPSG:3826 的距離（四捨五入到小數 1 位）。依 `dropped_osm_id` 的輸出排序（OSM 類型、數字 id）排列；沒有去重時只有標題列。CLI 新增必填參數 `--dedup-log`。

不寫進 `dedup_log.csv`，因為那個檔案由設施和官方對照兩個步驟產生，再加第三個來源會讓 Makefile 的相依關係變複雜。

### 大觀改成 part

`data/official/crosswalk.csv` 大觀那一列改成 `part`，`osm_ids` 不變，`note` 寫明原因。結果：三筆都保留，都有 `official_id` 和 `energy_primary`（水力），容量各自用 OSM 的值（1,000、110、`null`），不補官方值。`dedup_log.csv` 不再有大觀的 `official_same_plant` 紀錄。

## Implementation Contract

**行為**

- `make data` 後 `substations.geojson` 不含 `w942837398`、`w942837397`、`w659199805`、`w807986863`，仍含 `w323405078`、`w323413321`、`r17867618`；`substation_dedup_log.csv` 有這 4 列。實際數量以輸出為準，預期 784。
- `plants.geojson` 有 `w1105678337`（1,000 MW）、`w976767036`（110 MW）、`w515759414`（`capacity_mw` null），三筆的 `official_id` 都是 `tp-plant:大觀發電廠`。

**資料形狀**

- `substation_dedup_log.csv` 欄位如上；`substations.geojson` 的欄位、排序規則不變。

**失敗模式**

- 幾何無效（例如自相交）時，用 `make_valid` 修正後再算面積；修不好就視為沒有包含關係，不去重、不報錯。

**驗收**

- `tests/test_substations.py` 涵蓋：沒有名稱被包住（去掉）、有名稱被沒名稱的包住（去掉外面）、同名被包住（去掉裡面）、名稱不同被包住（保留）、只相鄰不重疊（保留）、包住比例 89%（保留）、去重紀錄的欄位和排序、沒有去重時只有標題列。
- `uv run pytest`、`make data` 成功；`stats.json` 的 `substations` 等於 `substations.geojson` 的筆數。

**範圍**

- 範圍內：`powermap/substations.py`、測試、Makefile、README、`crosswalk.csv` 大觀一列。
- 範圍外：設施去重規則、`same` 補值規則、網頁。

## Risks / Trade-offs

- [90% 門檻是主觀設定] → 目前 5 組都是 100% 包住，門檻只是容許邊界誤差；測試用 89% 確認門檻生效。
- [大觀整體範圍 `w515759414` 會多出一個未填能源、沒有容量的點] → Popup 會顯示官方主要能源為水力；這比少算 110 MW 更接近實際。
